- Record desired direction only; route evidence, premises, commitments and document content to their kinds.
- INTENT and DEC remain independently usable; don't make an INTENT a prerequisite for a DEC.
- One Current INTENT per exact `(scope, key)`. `supersede` requires a `replace` judgment made from both actual Intent bodies.
- Don't store inverse relations or install anything.
- Follow the active-language contract for user-facing text; keep machine fields in English and preserve artifact prose.
- Follow the shared [recording policy](../skills/context/references/recording-policy.md): `explicit` uses user semantic approval, `auto` uses project policy, and `adaptive` requires a record/ask assessment. Only enabled kinds participate automatically. The core is the only writer: `prepare` with authorization, `compare` and judgments when it returns `needs_review`, then `apply` of the unchanged handle in the same response. Never rebuild authorized meaning.
